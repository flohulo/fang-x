# Fang X Handbuch

Fang X ist ein GPS-Fangspiel für draußen. Eine Person ist **X** und versucht zu entkommen. Alle
anderen spielen als **Detektive** und bekommen regelmäßig Hinweise auf X' Standort. Wer X im
Fangradius erreicht, gewinnt.

Das Handbuch erklärt die Spielvorbereitung, alle Einstellungen und worauf ihr beim Spielen im
Freien achten solltet.

## Schnellstart

1. Eine Person erstellt ein Spiel und teilt den sechsstelligen Spiel-Code.
2. Alle treten bei und wählen ihre Rolle: X oder Detektiv.
3. Der Host legt Dauer, Vorsprung, Sichtungen und Fangregel fest.
4. Spiel starten, Standort erlauben – X läuft los, die Detektive suchen.

## Sicher spielen

!!! warning "Achtet aufeinander"
    Spielt nur an sicheren, öffentlichen Orten und respektiert die Privatsphäre anderer. Achtet
    auf den Verkehr, bleibt erreichbar und vereinbart vor dem Start einen Treffpunkt für das Ende.
    Wenn jemand nicht weiterspielen kann oder möchte, gibt es den
    [Notfall-Knopf](Notfall-Knopf.md).

## Ohne Konto, ohne Standortverlauf

Fang X braucht keine Benutzerkonten. Standorte werden nur während einer laufenden Runde
übertragen; Routenverläufe werden nicht gespeichert. Der Chat wird nach Spielende verworfen.
Mehr dazu im Impressum und in der Datenschutzerklärung der App.
