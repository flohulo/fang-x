# Getting started

## Creating a game

One person creates a new game on the start page. They become the host and play as X by default.
They share the six-character **game code** with the group – via the invitation link, via the
**QR code**, or by everyone entering the code and joining.

!!! tip ":material-qrcode: QR code for everyone on site"
    Tap **Show QR code** in the lobby. The others scan it with their phone camera and land directly
    in the game. The QR code contains the same link as **Share invitation**.

## Choosing a role

When joining, everyone chooses **X** or **detective**. In the lobby the host can still adjust
the roles of the other players. A round needs at least one X; detectives can join at any time
as long as the game has not started yet.

## Setting the rules

In the lobby the host adjusts the [game settings](Spieleinstellungen.md). All changes apply to
the upcoming round and are sent to all players. A good start is the **Classic** preset with a
game duration of 30 minutes, a 2-minute head start and a reveal every 3 minutes.

## Starting

After the start a short countdown runs. Then X's head start begins: X runs off, the detectives
start at the agreed meeting point. Allow location access in the browser so that the map can use
your location. Without GPS you can try out the game in **simulation mode** on the map.

## During the round

- **X** tries to stay inside the play area and survive until time runs out. If X leaves the
  area, the exact location is shared live with the detectives.
- **Detectives** see the map, the last reveal and – depending on the settings – the locations of
  the other detectives. Depending on the rule, a catch happens automatically within the catch
  radius or via a photo catch.
- Everyone can write in the chat. The history is deleted after the game ends.
- Detectives can talk over the [radio](Detektiv-Funk.md) without X listening in.

## End of the game

The round ends when X is caught, the game duration runs out or X gives up. Afterwards the app
shows the result and you can export the round's settings as a JSON file.

## Safety and emergencies

!!! warning ":material-alert: Stay in safe places"
    Stay in public, safe places and avoid dangerous areas.

If X has to call off the round, there is the [emergency button](Notfall-Knopf.md): after a
confirmation the game ends, the detectives win and receive X's exact location along with a
notification.

## App updates

When a new version is available, the app asks whether to reload. After **Reload** the version
history (changelog) opens automatically so you can see what is new. The back link takes you to
the home screen at any time, where a running game is resumed. You can also find the changelog in
the menu and via the version number on the home screen.
