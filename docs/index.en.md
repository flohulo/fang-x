# Fang X Manual

Fang X is a GPS chase game for the outdoors. One person is **X** and tries to escape. Everyone
else plays as a **detective** and regularly gets hints about X's location. Whoever reaches X
within the catch radius wins.

This manual explains how to set up a game, all the settings, and what to keep in mind when
playing outdoors.

## Quick start

1. One person creates a game and shares the six-character game code.
2. Everyone joins and picks a role: X or detective.
3. The host sets the duration, head start, reveals and catch rule.
4. Start the game, allow location access – X runs off, the detectives search.

## Playing safely

!!! warning "Look out for each other"
    Only play in safe, public places and respect other people's privacy. Watch out for traffic,
    stay reachable, and agree on a meeting point for the end before you start. If someone cannot
    or does not want to continue playing, there is the [emergency button](Notfall-Knopf.md).

## No account, no location history

Fang X does not need user accounts. Locations are only transmitted during a running round;
routes are not stored. The chat is discarded when the game ends. You can find more in the app's
legal notice and privacy policy.
